# Natural-Language-Processing
Transforming unstructured medical text into structured, queryable knowledge.

This repository implements a rule-based Natural Language Processing (NLP) pipeline to extract clinical entities and their relationships from the MultiCaRe dataset (a collection of PubMed clinical cases) and map them into a structured Knowledge Graph.

Built for the Natural Language Processing (2026) course, this project strictly relies on classical NLP techniques—proving that robust information extraction can be achieved through deep linguistic analysis, ontologies, and heuristics without relying on Large Language Models (LLMs).
