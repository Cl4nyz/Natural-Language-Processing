## Apresentação

O presente projeto foi originado no contexto das atividades da disciplina de
graduação [Processamento de Línguas Naturais](https://www.ic.unicamp.br/~santanch/teaching/nlp/2026-2/),
oferecida no segundo semestre de 2026 na Unicamp.

O objetivo é transformar narrativas clínicas do conjunto de dados MultiCaRe em
uma representação estruturada que possa ser utilizada na construção de um
Knowledge Graph. A extração é baseada em técnicas tradicionais e explicáveis de
NLP, como expressões regulares, dicionários e regras linguísticas. Não são usados
LLMs ou modelos Transformer para extrair os dados clínicos.
